# Step77 실행 검증 가이드

1. Step77 Windows EXE를 실행한다. 프로젝트/기존 DB를 삭제하거나 초기화하지 않는다.
2. PC에서 ComfyUI의 로컬 포트 8188을 실행하고 SD 체크포인트를 로딩한다. `Step77` 패널에서 연결 확인하면 체크포인트명이 실제로 표시되어야 한다.
3. 테스트용 스토리보드 장면과 허가받은 캐릭터 외형 텍스트를 편집한다. 생성 이미지 해상도/시드를 선택하고 이미지 생성한다.
4. 장면 미리보기·애니매틱·장면 타임라인을 확인한다. 출력 이미지 내보내기와 **전체 프로젝트 번들 백업→복원** 후 이미지가 유지되는지 확인한다.
5. 별도 체크포인트가 없거나 서버가 중지되면 오류가 표시되며, 기존 장면 이미지/오디오/프로젝트가 변경되지 않아야 한다.

실제 ComfyUI 추론 모델과 Windows 10/11 실기기에서는 아직 검증하지 못했다. 노드 인터페이스가 다른 모델(예: FLUX 전용 파이프라인)은 이 단계에서 지원하지 않는다.
