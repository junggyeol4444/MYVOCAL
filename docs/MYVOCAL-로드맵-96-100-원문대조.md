# MYVOCAL Studio 100단계 로드맵의 96~100단계 사용자 원문 대조

이 문서는 사용자가 현재 대화에서 지정한 100단계 계획 중 마지막 다섯 단계를 그대로 기재한 것입니다. 전체 1~95단계 순서와 66개 원본 기획안은 변경하지 않았습니다.

96. AI Creative Director — Music Director와 Video Director를 연결해 자연어 명령으로 음악·영상 프로젝트를 함께 수정한다.
97. CREATE SONG & VIDEO — 하나의 입력 화면에서 작사·작곡·편곡·가창·믹싱·스토리보드·MV 제작 작업을 실행한다.
98. 최종 내보내기 — 음원 WAV, MIDI, 영상 MP4, 자막 및 프로젝트 백업을 지원한다.
99. 통합 안정화와 품질 검증 — 실제 Windows PC에서 성능, 긴 작업, 데이터 보호, 프로젝트 호환성, 엔진 설치 및 오류 복구를 검사한다.
100. MYVOCAL Studio 완성 검증 — 사용자 목소리와 캐릭터 등록부터 AI 노래 제작, 실제 가창, MV 완성, 최종 저장까지 전체 과정을 검증하고 배포한다.

## 검증상 구분
코드/자동화 단계 진척과 실제 Windows·GPU·AI 모델의 최종 통합 검증은 다른 상태입니다. 특히 사용자 로드맵 99·100단계의 **실기기 및 전체 제작 품질 요건은 현재 미충족**입니다.
