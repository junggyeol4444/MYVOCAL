`내 목소리 학습→가창→AI 편곡→뮤직비디오/캐릭터 PV` 전체 흐름은 현 단계에서 완성되어 있지 않다. 주요 AI 엔진이 없으므로 프런트엔드 기능/자동 테스트 개수만으로 높은 완성도를 주장할 수 없다.

## Step30의 증분 성과

Step29의 오프라인 선택 구간 미리 듣기 WAV를 **원곡 시간에 유지한 채 새 오디오 트랙으로 추가**하도록 구현. BPM을 바꿔도 삽입 시각을 계산하는 `startBar = 1 + startSec × BPM / 240`가 음악 타임라인의 실수 마디 좌표에 반영된다. 구간 렌더링 이후 가사/MIDI가 변한 경우 재생성 안내, 잘못된 시작 시간 거부, 기존 트랙·음성·영상 보존. 프레임 반올림에 따라 최대 한 오디오 샘플 정도의 시간 오차 가능. 저장된 트랙은 기존 마디 좌표 모델을 그대로 따르므로 **삽입 후 프로젝트 BPM을 변경하면 다른 오디오 클립처럼 절대 시간 위치가 변할 수 있음**.

## 이후 중요한 목표

1. 외부 서버 없이 실제 로컬 AI 모델 설치·관리·권한 확인·보컬 추론을 작동시킨다.
2. 음악 자동 제작/편곡/믹싱 품질을 실제 노래 파일로 검증한다.
3. 캐릭터의 정체성 보존과 실제 MV 생성·립싱크·영상 내보내기를 구현한다.
4. Windows 10 x64와 Windows 11 x64 각각에서 설치/재실행·기존 데이터 보존을 실측한다.

GitHub 업로드/커밋/병합과 예약 자동화는 사용자의 현재 지시에 따라 실행하지 않는다.
