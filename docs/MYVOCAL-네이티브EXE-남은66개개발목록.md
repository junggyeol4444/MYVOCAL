# MYVOCAL Studio — 웹 제거 후 남은 전체 개발 작업 (Windows 네이티브 EXE)

작성 기준: 2026-10-27. 원본 66개 기획 요구사항(번호 유지) 및 현재 GitHub main 네이티브 소스와 대조.

## 사용자가 지정한 변경 불가 원칙

- 제품 실행 형태: Windows 10/11 x64 로컬 네이티브 GUI EXE. HTTP 서버, HTML, JavaScript 웹 화면, React, 브라우저, WebView2, 웹앱 재도입 금지.
- 원본 66개 기능을 없애거나 축소하는 것이 아니라 **해당 기능을 EXE에 완전히 구현**할 것. 웹 파일을 삭제했다는 이유로 기능을 완료라고 판정하지 않음.
- 기존 사용자의 녹음·음원·모델·사진·영상·프로젝트·설정·백업 파일은 무단 삭제·덮어쓰기 금지. 코드 저장소의 웹 소스는 삭제 지시대로 제거.
- 사용자가 지정한 작업 순서: 남은 기능 전부 개발 → 전체 검증 → 발견 오류 수정 → 재검증.
- 외부 서버나 브라우저 기반 인터페이스 금지. 소유자가 이미 설치한 로컬 AI 모델·Python 등을 직접 사용. 강제 재설치 금지.
- 누적 완성 기능은 main에 소스로 반영. 작업·검증 미완료를 숨기지 않음.

## 현재 확인 가능한 네이티브 구현 기반

GitHub main의 desktop/native/에는 Win32 컨트롤 기반 단일 네이티브 GUI와 runner, 오프라인 PCM 믹싱, 장편 MusicGen 중단 재개 소스가 있다.
GUI에 연결된 모드 9종: 단편 MusicGen, RVC 학습, Demucs 분리, MIDI 가창 음정 보정, 2D 립싱크 WebM, RVC 체크포인트 변환, DiffSinger 한국어 가창, MusicGen 장편, 반주/보컬 PCM 믹싱.
9개는 UI 작업 메뉴 개수이며 66개 요구사항 중 9개를 완성했다는 뜻이 아니다. 외부 모델의 실제 AI 실행·음질·모델 학습·Windows 10/11 실사용 전 과정 완료는 입증되지 않았다.

## 추가 필수 통합 개발 항목 (원본 66개를 바꾸거나 늘리는 별도 제품 기획이 아님)

- Windows 네이티브 멀티화면: 메인 대시보드, 음악 편집기(파형/트랙/MIDI), AI 작사/작곡, 보컬 녹음·학습실, 캐릭터/사람 등록, 스토리보드·MV 작업실, 라이브러리, 프로젝트/설정.
- 기존 IndexedDB 사용자 프로젝트를 잃지 않고 네이티브 로컬 프로젝트 형식으로 **사용자가 선택해** 가져오는 기능. 웹앱을 다시 실행하거나 HTTP 서버를 붙여 해결하지 않음. 이전 파일을 직접 읽거나 호환 가능한 오프라인 백업 파일을 이용.
- 작업 결과 실제 파일 출력(예: WAV/MIDI/MP4), 모델 설치 감지, 반복 작업·중단 재개, 오류 로그·자산 무결성 및 데이터 보호.
- 사용자 PC에 존재하는 Python/AI 엔진·모델 경로를 우선 자동 탐색하며 강제 재설치하지 않음.
- 모든 기능 코딩 완료 이후 Windows 10/11 GUI 실행·입력/버튼·실제 학습/생성·저장/재실행·전체 통합 검증, 그다음 발견한 오류 수정.

## 검증 가능한 현재 범위와 주의

2026-10-27 기준 현재 main에 네이티브 Win32·Python 워커·기획 문서를 합쳐 약 26개 파일이 있으며, 삭제된 웹/HTTP 소스는 최신 트리에 없다. 기존 웹 UI 파일 735개를 제거한 뒤 66개 기능이 현재 네이티브로 대체 구현되었다는 근거는 **없다**.
작업 정확한 수량·진행률 %·완료 예상 시점은 각 요구사항별 실제 개발 완료·테스트 증빙 없이는 계산하지 않는다.
