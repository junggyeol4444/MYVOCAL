# MYVOCAL Studio — 오프라인 로컬 실행 방침 (Step24)

## 운영 구조

- **앱 실행**: Windows x64 EXE를 PC에서 직접 실행. GitHub, 계정 로그인, 인터넷, 클라우드 서버를 요구하지 않음.
- **화면**: EXE에 포함된 HTML/JS를 PC의 `127.0.0.1:58319` 로컬 HTTP 엔드포인트로 제공하고 PC에 설치된 Edge/Chrome 앱 모드 또는 사용자가 별도로 준비한 WebView2 런타임에서 표시함. `127.0.0.1`은 인터넷 서버가 아님.
- **파일 저장**: 기존 Windows 사용자 프로필 `%LOCALAPPDATA%\MYVOCAL Studio` 와 전용 Chromium/WebView2 프로필의 localStorage/IndexedDB. 이전 프로젝트·WAV·동영상 및 사용자가 저장한 프로필은 자동 삭제·이동·초기화하지 않음.
- **새 Step24 정책**: 외부 OpenAI 작사 프록시 경로와 API 키 입력 UI 제거. 외부 Google Fonts 요청 제거. 앱의 콘텐츠 보안 정책에서 `connect-src 'self'`, `default-src 'none'` 으로 외부 사이트 연결 차단.
- **브라우저 측면 주의**: 시스템에 설치된 Edge/Chrome/WebView2 런타임 자체가 자동 업데이트·정책상 네트워크 통신을 시도할지는 앱만으로 완전히 통제할 수 없음. 실행 전 설치된 런타임 필요.
- **가창 엔진**: 사용자가 따로 설치하고 실행하도록 지정한 로컬 프로세스 및 127.0.0.1 포트에만 연결. 외부에서 다운로드하지 않고 자동 모델 학습도 하지 않음.
- **GitHub**: 실행에 필요하지 않으며 개발 결과물에 GitHub 자동화 설정이 없음.

## 가능한 로컬 기능과 아직 미완성인 기능

- 로컬 작곡 템플릿, 코드 진행, 규칙 기반 MIDI, WAV 재생·내보내기, 장르·곡 구간 편집, 프로젝트 저장 기능은 소스에 포함됨.
- 완성형 **신경망 AI 음악 생성·목소리 학습·한국어 가창·영상 프레임 생성** 모델은 내장되지 않았음. 현 Step24 결과물을 그 기능이 모두 완성된 프로그램이라고 표현하지 않음.

## Windows 실기기 QA (미완료)

Windows 10 x64와 11 x64에서 각각 인터넷을 끊은 뒤 EXE 기동·창 실행, 프로젝트 생성·저장·재실행, MIDI·WAV 출력, 음성 녹음·기존 미디어 원본·프로필 보존을 시험해야 함. Linux에서 Go를 Windows 대상으로 크로스 빌드한 결과는 실기기 검증이 아님.

## Step25 추가 — 내장 오프라인 가창 가이드

- **보컬 작업실 → B. 내장 오프라인 가창 가이드** 에서 가사·MIDI 싱크를 만든 뒤 **오프라인 가창 가이드 WAV 생성** 을 누릅니다.
- JavaScript DSP가 한글 모음의 단순 주파수 특성과 음표의 MIDI 음높이·시간·강약을 WAV로 생성합니다. 가창 모델, Python, 외부 API, 인터넷 또는 127.0.0.1 가창 서버가 **필요하지 않습니다**.
- 결과를 즉시 듣거나 WAV로 다운로드할 수 있고, 사용자가 직접 **프로젝트 오디오 트랙에 추가** 버튼을 눌러야 프로젝트 저장소에 별도 오디오 원본으로 기록됩니다. 기존 오디오·MIDI·영상·목소리 프로필은 덮어쓰지 않습니다.
- 22,050Hz, 모노, 16비트 PCM WAV. 최대 90초·128음표·누적 발음 길이 120초.
- 이 가이드는 자연스러운 발음이나 사용자의 목소리를 재현하지 않습니다. 신경망 AI 음성 합성 또는 보컬 학습 기능이라고 부르지 않습니다.
