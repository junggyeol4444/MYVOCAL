# Step73 — 오프라인 MV 스토리보드 애니매틱

## 기능
- Step72까지 저장한 `project.scenes`를 **읽기 전용**으로 사용하고, Scene Properties에서 작성한 제목·설명·카메라·장소·동작 메모를 시간에 맞춰 텍스트 카드로 미리 확인합니다.
- 재생/일시정지, 처음으로 이동, 타임라인 이동, 장면 시작으로 이동, 0.5/1/2배 속도를 지원합니다.
- 장면이 없는 시간 구간은 '장면 없는 구간'으로 표시합니다. 겹침, 중복 장면 ID, 잘못된 시간, 존재하지 않는 캐릭터 연결이 있으면 재생을 차단합니다.
- `장면 제목 SRT 가이드`는 장면 제목을 구간별로 넣은 **편집용 안내 자막**입니다. 가사·음성 정렬 또는 실제 영상 캡션이라고 간주하면 안 됩니다.

## 데이터 보존 및 로컬 정책
- 기존 프로젝트, 브라우저 프로필, 캐릭터, 음악, 보컬, 이미지/비디오 파일의 **읽기·수정·삭제 없이** 기존 스토리보드 필드만 사용합니다.
- 기존 프로젝트 데이터 스키마 및 Step71/72 JSON 형식 변경 없음. SRT는 파일을 로컬에 직접 다운로드합니다.
- 네트워크 요청, 외부 AI, 영상 프레임 합성, 립싱크, 비디오 출력 기능 없음.

## 검증
- `node --test tests/mv-animatic.test.mjs`
- `node --test --test-concurrency=1 tests/*.test.mjs`
- `node scripts/build-standalone.cjs` 및 `source/desktop/index.html` 동기화
- Windows x64 실행 파일 크로스 빌드는 가능하나 Windows 실기기 실행은 별도로 확인해야 합니다.
