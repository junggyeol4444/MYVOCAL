# Step70 — 캐릭터 제작 계획 무결성 확인

## 사용 방법
1. Character Studio에 캐릭터, 룩, MV 컷, 보컬 큐를 수동으로 등록합니다.
2. STEP69 제작 점검에서 오류/경고를 확인합니다.
3. STEP70의 **제작 계획 검증 패키지 저장**을 눌러 메타데이터 기반 JSON을 생성합니다.
4. 이후 같은 프로젝트와 동일한 캐릭터 표시 선택 상태에서 **검증 패키지 확인**으로 JSON 파일을 선택합니다.
5. SHA-256 및 현재 계획 재계산값의 일치 여부를 화면의 상태 메시지로 확인합니다. 검증 시 사용자 데이터를 수정하지 않습니다.

## 정보 보호
- JSON은 캐릭터 ID, 컷 ID·시간·보컬 큐 수, 검토 이슈 코드, 집계 정보만 포함합니다.
- **가사/대사 원문, 제작 방향 메모, 원본 음원, 영상, 이미지, 3D 모델 바이트를 포함하지 않습니다.**
- SHA-256은 무결성 검사로, 파일 작성자 신원·자료 이용 권한의 진위 증명이 아닙니다.
- 최대 512KiB 제한. 파일 내용이나 현재 계획이 바뀌면 검증이 실패합니다.
- 빈 계획은 점검 통과로 취급하지 않습니다. 경고·오류가 남으면 `reviewPassed`는 `false`입니다.
- 저장·검증은 로컬 WebCrypto를 이용하며 외부 서버로 보내지 않습니다.
