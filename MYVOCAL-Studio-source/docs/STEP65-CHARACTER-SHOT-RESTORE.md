# Step65 — Character Studio MV 컷 계획 JSON 복원 및 타임라인

Step64의 수동 컷 계획을 JSON으로 내보낸 뒤 같은 ID의 캐릭터로 다시 가져올 수 있습니다. 원본 이미지·음악·영상·프로젝트 파일은 포함하지 않습니다.

- 컷 계획 JSON 최대 512 KiB(UTF-8 바이트). 같은 캐릭터 ID, 지원 포맷 및 버전 1만 허용합니다.
- 등록된 룩만 연결 가능하며 컷 ID/이름 중복, 기존 컷과의 중복, 컷 간 시간 겹침을 모두 검사합니다.
- 모든 컷이 유효할 때만 기존 컷 뒤에 **추가**합니다. 충돌하는 항목이 하나라도 있으면 아무 항목도 가져오지 않습니다.
- 기존 컷을 삭제하거나 덮어쓰지 않으므로, **같은 JSON을 같은 컷이 이미 있는 캐릭터에 다시 가져오면 중복 오류**가 납니다.
- 가져온 컷의 원래 생성/수정 시각은 유지합니다. 캐릭터의 외형 시트와 첨부 자료는 변경하지 않습니다.
- 타임라인은 컷의 시작/종료 시각과 빈 구간을 표시합니다. 기준 룩이 누락됐거나 외형 기준 재검토가 필요하면 색으로 경고합니다.
- 영상 렌더링·인공지능 얼굴 인식·자동 립싱크·씬 합성 및 Windows 실기기 작동은 이 기능에서 검증되지 않았습니다.

예제: `examples/step65/character-shot-plan-example.json` 은 합성 캐릭터 컷 2개이며, 해당 ID와 `sample-look` 룩이 있는 캐릭터에만 가져올 수 있습니다. 검증 결과는 `examples/step65/restore-verification.json`을 참고하세요.
