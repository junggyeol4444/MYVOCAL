# Step40 — WAV PCM 16/24비트 내보내기 (오프라인)

오디오 · MIDI 멀티트랙 편집기의 WAV 믹스 저장 옆에서 **PCM 16비트(기본값)** 또는 **PCM 24비트**를 선택합니다. 선택은 해당 편집 세션의 내보내기 옵션이며 프로젝트 JSON이나 원본 WAV/미디어에는 기록되지 않습니다.

- 두 형식 모두 44.1 kHz, 2채널, little-endian RIFF/WAVE, PCM 정수 형식입니다.
- 24비트는 샘플당 3바이트를 사용하므로 16비트보다 PCM 데이터가 1.5배 큽니다. 원본 음질을 복원하거나 실제 입력의 비트 깊이를 늘리지는 않습니다.
- Step39의 선택형 -1 dBFS **샘플 피크 보호**를 두 형식에 함께 사용할 수 있습니다. 트루 피크 리미팅, 디더링, LUFS 정규화 또는 마스터링은 하지 않습니다.
- 기존 `mixdownWav(project)`는 기본 16비트 Blob API와 PCM 값을 유지합니다. 새 사용 예: `mixdownWavDetailed(project, {bitDepth:24, peakProtection:true})`.
- 지원하지 않는 비트 깊이(예: 8, 32)는 조용히 변환하지 않고 오류로 거부합니다.
- Windows 10/11의 실제 GUI/오디오 장치 실행 및 타사 편집기에서 WAV 파일 열기 테스트는 별도로 필요합니다.
