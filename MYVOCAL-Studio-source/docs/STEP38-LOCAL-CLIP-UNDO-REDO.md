# Step38 — 오디오 클립 편집 실행 취소 / 다시 실행

## 사용법

1. 오디오·MIDI 멀티트랙 편집기에서 클립의 시작 위치, 자르기, 페이드, 음량, 음소거, 좌우 위치를 수정하거나 클립을 복제·분할·제거·가져옵니다.
2. 상단의 **↶ 클립 취소**를 누르면 해당 클립 변경 한 건을 취소합니다.
3. **↷ 다시 실행**을 누르면 취소한 변경을 다시 적용합니다.
4. 최근 **40건**의 클립 변경을 기록합니다. 취소한 뒤 새로운 편집을 하면 다시 실행 기록은 초기화됩니다.

## 안전 범위와 제한

- 현재 편집 화면의 **세션 내 기록**만 유지합니다. 다른 프로젝트로 이동하거나 화면을 닫거나 새로고침하면 기록이 초기화될 수 있습니다.
- 각 기록에는 **수정한 트랙의 클립 목록만** 저장합니다. 다른 트랙, 트랙 볼륨·음소거·이름, MIDI 노트, 가사, BPM, 영상 등은 실행 취소의 대상이 아닙니다.
- 원본 WAV, 로컬 IndexedDB 미디어, 브라우저/WebView2 프로필은 변경·삭제하지 않습니다. 오디오 가져오기를 취소해도 이미 가져온 미디어 파일은 보존됩니다. 이로 인해 참조되지 않는 미디어가 남을 수 있습니다.
- 다른 화면에서 같은 클립이 변경되어 기록과 현재 클립이 일치하지 않으면 덮어쓰지 않고 오류를 표시합니다. 기록은 보존됩니다.
- 프로젝트 파일 형식 및 저장소 버전을 변경하지 않습니다. 기존 프로젝트는 이전과 동일하게 열립니다.
- 실제 Windows 10/11 PC의 GUI·스피커·WebView2 작동은 아직 검증하지 않았습니다.

## 구현

- `src/lib/clipHistory.js`: 순수 함수 `createClipHistory`, `recordClipChange`, `applyClipHistory`.
- `src/components/AudioWorkstation.jsx`: 클립 편집·분할·복제·가져오기·제거 기록 및 취소/다시 실행 버튼.
- `tests/clip-history.test.mjs`: 변경 내역/충돌/제한/프로젝트 격리 테스트.
- `tests/clip-pan-integration.test.mjs`: 실제 오디오 엔진 함수와 모의 Web Audio 환경에서 분할 취소·다시 실행 후 WAV PCM 및 재생 소스 수 확인.
