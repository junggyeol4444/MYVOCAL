# Step33 — 오프라인 오디오 페이드 곡선

## 추가된 기능
- 각 오디오 클립에서 페이드 인·아웃 시간을 유지한 채 **서로 다른 곡선**을 선택할 수 있습니다.
- **직선(linear)**: 균일한 음량 기울기.
- **부드럽게(smooth)**: 초반·후반 기울기가 완만한 smoothstep.
- **등전력(equalPower)**: sin(π·진행률/2) 기반 오디오 진폭 변화. 겹치는 두 클립의 곡선은 독립적이며 자동 크로스페이드 연결 기능은 아닙니다.
- 기존 프로젝트에 곡선 값이 없으면 자동으로 기존 직선형을 사용합니다. 필드 `fadeInCurve`, `fadeOutCurve`만 선택적으로 JSON에 저장합니다.
- 원본 WAV·미디어·IndexedDB·사용자 프로필 데이터는 변경하지 않습니다.
- `clipFadeGain`과 `scheduleClipFade`를 실시간 재생 및 오프라인 WAV 믹스가 공유합니다.
- 직선은 기존과 동일한 최소 제어점, 비선형 곡선은 각 페이드당 최대 32 구간의 Web Audio 직선 램프를 사용합니다.
- 클립 도중 탐색할 때 페이드를 다시 시작하지 않고 원래 경과 시점에 맞는 값으로 처리합니다.

## 사용 방법
1. 음악 작업 공간 → 오디오·MIDI 멀티트랙 편집기에서 오디오를 가져옵니다.
2. 페이드 인·아웃 시간을 초 단위로 입력합니다.
3. **페이드 인 곡선**과 **페이드 아웃 곡선**을 각각 선택합니다.
4. 재생하거나 WAV 믹스를 내보내면 같은 페이드 곡선이 적용됩니다.

## 오프라인/안전성
- 로컬 Web Audio 합성. 인터넷 및 GitHub 연결 필요 없음.
- 테스트 샘플 WAV는 로컬 사인파로 생성했으며 사람 목소리나 AI 가창이 아닙니다.
- Windows 10·11 실제 PC에서 WebView2 GUI 및 프로젝트 재실행 검증은 아직 완료되지 않았습니다.
