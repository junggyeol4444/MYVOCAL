# Step45 — 로컬 WAV 샘플 피크 정규화

- 원본 66개 기획의 믹싱/마스터링 관련 기능을 향한 **제한된** 추가 기능이며 별도 100단계 계획이 아님.
- WAV 내보내기에서만 **피크 정규화 (-1 dBFS, 최대 +12 dB)** 체크박스 제공. **기본 꺼짐**.
- 실제 출력 채널(모노는 `(L+R)/2`, 스테레오는 L/R), 앞뒤 무음 제거 후 구간, 경계 5ms 페이드의 결과를 기준으로 샘플 피크를 분석함.
- 신호가 조용하면 한 번에 최대 +12 dB까지 증폭하고, 크면 -1 dBFS까지 감쇠함. 완전 무음은 증폭하지 않음.
- 피크 정규화와 기존 피크 보호를 함께 선택하면 **정규화가 우선**함. 정규화를 끄면 Step44까지의 기존 기본 WAV 출력 바이트는 그대로 유지됨.
- 전체 채널에 동일한 gain을 적용하며 원본 AudioBuffer·클립·프로젝트·미디어 저장소·WebView2 프로필을 수정하지 않음.
- **한계:** 샘플 피크 기준이며 LUFS/트루 피크 정규화, 컴프레서, 리미터, 전문 마스터링이 아님. +12 dB 증폭은 배경 잡음도 키울 수 있음. 정규화 후의 인코딩 양자화와 실제 재생기 인터샘플 피크는 별개임.
- 테스트: `node --test tests/wav-normalize*.test.mjs`, 전체 `npm test`. 데모: `node scripts/demo-wav-normalize-step45.mjs <출력 폴더>`.
- Windows 10/11 실기기, 실제 WebView2 재생·내보내기 검증은 별도 필요.
