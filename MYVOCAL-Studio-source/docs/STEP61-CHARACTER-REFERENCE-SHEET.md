# Step61 · Character Studio 수동 Identity Reference Sheet

## 구현
- 기존 Character Library의 사람/2D/3D 캐릭터 등록 화면에 **편집 모드** 추가. 캐릭터 ID와 등록일 유지.
- 머리, 눈, 기본 의상, 색상 팔레트, 장신구, 체형, 성격/분위기의 사용자 입력 메타데이터 저장.
- 원본 이미지/동작 영상/3D 파일에 정면, 측면, 후면, 전신, 표정, 의상, 동작 참고, 3D 모델 등 역할 부여.
- 기존 자산은 편집 도중 목록에서 제거할 수 없으며 새로운 첨부 자료는 모두 로컬 IndexedDB에 추가.
- 사용 허가 자료는 출처·허가 범위 입력 필수; Reference 전용 자료는 캐릭터 등록 권한으로 허용하지 않음.
- 파일당 40 MiB, 캐릭터당 총 64개 자료, 지원 파일 확장자/타입, 파일명, 역할의 일관성 검사.
- 신규 자료 등록에 실패하면 해당 작업에서 성공적으로 저장한 새 파일 삭제를 시도. 기존 자료는 건드리지 않음.
- 사용자가 쓴 설정은 기존 앱의 로컬 상태 저장 구조에 그대로 저장되므로 프로젝트는 기존 캐릭터 ID를 계속 참조.

## 기존 프로젝트와의 호환성
- 기존 캐릭터 객체에 새 `identityProfileVersion`, `appearance`, `rightsNote`, 각 자산의 `role`를 **추가**. 구버전 자산은 편집 시 기본값 `other`로 해석.
- 앱 전체의 localStorage 키나 IndexedDB 파일 저장소를 교체하거나 자동 초기화하지 않음.
- 기존 캐릭터를 수정하면 기존 ID와 자산 ID를 유지하여 프로젝트 링크를 보호.

## 한계
- 실제 얼굴 추출, 이미지 분할, 표정 시트 생성, AI 캐릭터 생성, AI Identity Lock, VRM 렌더링은 아직 제공하지 않음.
- 파일 확장자·브라우저 MIME 기반 검사는 보안용 콘텐츠 스캔을 대체하지 않음.
- 이 단계는 사용자가 제출한 권한 근거를 기록할 뿐 법적 사용 허가의 진위 여부를 검증하지 않음.
- 오프라인 Windows EXE는 교차 빌드로 생성했으나 실제 Windows 10/11 GUI 실행 여부는 시험하지 않음.
