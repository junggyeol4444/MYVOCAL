# Step49 — WAV 출력 샘플 피크·RMS·클리핑 위험 표시

이 기능은 MYVOCAL Studio의 로컬 음악 믹싱/마스터링 보조 기능이며 AI 마스터링 엔진이 아닙니다.

## 사용 방법

오디오/MIDI 멀티트랙 편집기에서 WAV 내보내기를 실행하면, 완료 메시지에 출력 샘플 피크(dBFS)와 RMS(dBFS)가 표시됩니다. 출력 범위, 채널 수, 앞뒤 무음 제거, 피크 보호/정규화, 경계 5ms 페이드 설정을 반영합니다. 기본 WAV 출력 파일은 Step48과 동일한 방식으로 생성됩니다.

출력 샘플 절대값이 1.0을 초과하면 경고합니다. 16/24비트 PCM에서는 양자화 시 해당 샘플이 잘려 나가고, 32비트 float에서는 WAV 값은 유지되지만 재생 프로그램에서 클리핑될 수 있습니다. 피크 보호 또는 정규화를 선택하면 위험을 줄일 수 있습니다.

**한계:** 검사는 오프라인 렌더링 결과의 *양자화 전* 샘플에 수행됩니다. 16비트 TPDF 디더와 최종 정수 양자화는 측정치에 포함되지 않습니다. 0 dBFS 정확히 일치하는 샘플은 '초과'로 집계하지 않습니다. RMS는 LUFS, 트루 피크, 인터샘플 피크, 실제 청감 음량이 아닙니다. 비정상 NaN/무한대는 인코더에서 0으로 대체될 수 있으므로 별도 감지합니다.

## 기술·보존 범위

- `src/lib/wavExportMeter.js`에서 출력 프레임/채널을 순회하며 피크, RMS, 0 dBFS 초과 샘플·프레임 수, 비정상 샘플 수를 계산합니다.
- `src/lib/audioEngine.js`가 기존 인코더 호출과 동일한 선택 범위·음량·경계 페이드를 전달하고 `outputReport`를 반환합니다.
- `src/components/AudioWorkstation.jsx`는 기존 WAV 저장 완료 알림에 검사 수치를 표시합니다.
- 프로젝트 스키마, 사용자 오디오/영상 파일, IndexedDB 및 WebView2 프로필 저장 코드는 수정하지 않습니다.
- Windows 10/11 실기기에서의 UI 표시·오디오 재생·파일 호환성은 별도로 검증해야 합니다.
