# Step42: WAV 모노(1채널) 출력

## 동작

오디오·MIDI 멀티트랙 편집기의 **WAV 채널** 메뉴에서 `스테레오(기본)` 또는 `모노`를 선택한 뒤 WAV 믹스를 저장합니다. PCM 16/24비트와 44.1/48kHz를 모두 조합할 수 있습니다. 기존 프로젝트·원본 미디어·실시간 재생 설정은 바뀌지 않습니다. 이 설정은 화면의 내보내기 옵션으로만 유지되며 프로젝트 JSON에 저장되지 않습니다.

모노는 먼저 스테레오 2채널로 오프라인 믹싱한 후 각 프레임을 `(L + R) / 2`로 합산하여 1채널 PCM WAV로 인코딩합니다. **위상이 반대인 좌우 소리는 일부 또는 전부 상쇄될 수 있습니다.** 모노를 선택하면 좌우 배치 효과는 합산된 하나의 채널로 바뀝니다. 스테레오 모드는 이전 인코딩과 동일하며 기본값을 변경하지 않습니다.

선택형 **-1 dBFS 피크 보호**는 모노 출력일 때 합산 후의 샘플 피크를 기준으로 감쇠량을 계산합니다. 합산 전에 채널마다 보호를 적용하면 불필요하게 음량이 줄어들 수 있으므로 피했습니다. 모노는 전체 파일에 하나의 감쇠 배율을 사용하며 원본 PCM을 수정하지 않습니다. 트루 피크/라우드니스 마스터링이 아닙니다.

## 검증 한계

`tests/wav-mono.test.mjs`는 실제 인코더의 WAV RIFF 헤더, 16/24비트 PCM, 44.1/48kHz, 모노 다운믹스, 위상 상쇄, 피크 보호, 유효성 검사, 원본 데이터 보존을 검사합니다. `tests/wav-mono-integration.test.mjs`는 실제 믹서 함수에 **모의 Web Audio 컨텍스트**를 연결해 옵션 전달 및 결과 파일을 검사합니다. 실기기 Windows 10/11의 WebView2 재생·내보내기 품질은 별도로 검증해야 합니다.

Windows x64 GUI 실행 파일은 교차 빌드 결과이며, WebView2Loader.dll/런타임 등 필요한 구성 요소가 사용자의 환경에 실제로 있는지 확인하지 못했습니다. 네트워크 없이 동작하도록 설계하지만 모든 Windows 환경에서의 실행 성공을 보증하지 않습니다.
