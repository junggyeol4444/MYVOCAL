# Step43 — WAV 앞뒤 무음 제거 (로컬 전용)

## 동작

- WAV 내보내기에서 `앞뒤 무음 제거 (-60 dBFS)` 체크박스를 **명시적으로 켠 경우에만** 적용한다. 기본값은 꺼짐이며 기존 `mixdownWav(project)` 출력 길이·PCM을 바꾸지 않는다.
- `OfflineAudioContext`에서 믹싱한 **출력 채널 기준**으로 -60 dBFS 이상인 첫 프레임과 마지막 프레임을 찾고, WAV 인코딩 시 이 구간만 쓴다. 모노는 먼저 `(L+R)/2` 다운믹스를 계산해 판정한다.
- **중간 무음은 제거하지 않는다.** 완전히 무음이거나 -60 dBFS 미만인 파일은 잘라낼 수 있는 구간이 없다고 보고 전체 길이를 유지한다.
- 피크 보호가 켜져 있으면 최종 출력 프레임 범위에서만 피크를 계산해, 선택한 출력 채널 기준으로 -1 dBFS 이하로 감쇠한다. 무음 탐지 임계값은 피크 감쇠 **전** 샘플 기준이다.
- 원본 미디어·클립·프로젝트 데이터·재생 위치·브라우저 프로필은 수정하지 않는다. 오프라인 렌더링 버퍼도 변경하지 않고, PCM 인코더가 선택된 구간만 읽는다.
- 16/24비트, 44.1/48kHz, 모노/스테레오 조합을 지원한다. 결과물의 `RIFF` 길이·데이터 길이·채널 수는 실제 인코딩한 프레임 수와 일치한다.

## 주의

- 의도한 도입부/후미 여백이나 매우 작은 소리가 잘릴 수 있다. 필요하면 옵션을 끈다.
- 게이트/노이즈 제거/무음 구간 압축/마스터링이 아니다. 리샘플링 품질이나 Windows WebView2 실기기 동작은 별도 검증이 필요하다.
- 실제 AI 보컬 학습/가창/영상 생성 기능을 구현한 단계가 아니다.
