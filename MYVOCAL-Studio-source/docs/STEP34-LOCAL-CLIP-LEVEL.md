# Step34 — 클립별 음량 및 음소거 (완전 로컬)

## 기능
- 오디오 클립마다 **클립 음량(0~200%)** 및 **음소거**를 별도로 지정할 수 있습니다.
- 음량은 선형 진폭 배율입니다. 예: 50%=0.5배, 100%=1배, 200%=2배. 100%를 초과하면 최종 WAV의 16비트 PCM에서 클리핑이 발생할 수 있습니다.
- 페이드 인·아웃과 트랙 볼륨/음소거/솔로는 기존대로 독립적으로 동작합니다.
- 실제 재생과 WAV 내보내기 모두 `scheduleClipLevel`을 이용해 동일한 별도 GainNode를 사용합니다.
- 음량이나 음소거를 변경하는 도중 재생 중이었다면 재생을 중지합니다. 새 설정을 들으려면 다시 재생하십시오.
- 오디오 파일, 미디어 DB, 기존 프로젝트 저장 방식은 수정하지 않습니다. 프로젝트 JSON에 `gainPercent`, `clipMuted`를 선택적으로 저장합니다.
- 이전 프로젝트에 해당 값이 없으면 **음량 100%, 음소거 해제**가 기본값입니다. 손상된 저장 음량은 재생 시 안전하게 100%로 처리합니다.

## 사용 방법
1. 음악 작업 공간 → 오디오·MIDI 멀티트랙 편집기에서 오디오를 가져옵니다.
2. 하단 클립 목록에서 **클립 음량(%)** 숫자를 0~200으로 조절합니다.
3. 필요하면 **음소거** 체크박스를 선택합니다.
4. 실시간 재생 및 **WAV 믹스 저장**에서 변경 사항을 확인합니다.

## 검증 범위
- 순수 함수/입력 검증/레거시 호환성 테스트.
- Web Audio/IndexedDB 모의 객체를 이용한 **실제 AudioEngine.play / mixdownWav 경로** 테스트 (Windows 실기기나 실제 스피커 검증은 아님).
- 4.5초 합성 사인파 WAV 샘플: 100%, 50%, 음소거를 순서대로 포함. 실제 AI 보컬 생성은 아님.
- Windows 10·11 x64 실기기 GUI/WebView2 실행과 실제 청취는 미검증.
- GitHub, 외부 서버, 클라우드 AI API 불사용.
