# Step35 — 오디오 클립 좌우 위치(스테레오 팬)

## 사용 방법
음악 작업 공간 → 오디오·MIDI 멀티트랙 편집기 → 하단 클립 목록의 **클립 좌우 위치(-100~100)** 에서 수치를 입력합니다.

- `-100`: 완전히 왼쪽, `0`: 가운데, `100`: 완전히 오른쪽.
- 값은 각 오디오 클립의 선택적 `panPercent` 필드에만 저장합니다. 원본 오디오 파일은 수정하지 않습니다.
- 재생 중 위치를 변경하면 기존 안전 정책에 따라 재생을 멈춥니다. 다시 재생하면 새 설정이 적용됩니다.
- 실시간 재생과 오프라인 16비트 스테레오 WAV 내보내기에서 동일한 `connectClipAudio()` 경로를 사용합니다.
- 트랙 음량/음소거/솔로, 클립 음량/음소거, 페이드 및 비파괴 자르기와 독립적으로 적용합니다.

## 하위 호환 및 음량 처리
- 기존 프로젝트의 `panPercent` 필드가 없거나 0이면 스테레오 팬 노드를 **생성하지 않습니다**. 이전 재생 경로와 채널별 음량을 유지합니다.
- 값이 잘못된 경우(문자열, 범위 밖, NaN 등) 안전하게 가운데(0)로 처리합니다.
- 좌우 이동 시 브라우저 Web Audio의 `StereoPannerNode`를 사용합니다. 모노 오디오의 경우 지배적인 채널의 진폭을 원본과 같게 만드는 보정 GainNode를 추가해 가운데 부근의 음량이 불연속으로 떨어지는 현상을 막습니다. 스테레오 입력에는 이 모노 보정을 적용하지 않습니다.
- 해당 오디오 환경에서 `StereoPannerNode`를 지원하지 않으면 **좌우 배치가 설정된 클립을 재생/내보내기 할 때 명시적으로 오류를 표시**합니다. 임의로 가운데 믹스로 내보내지 않습니다.
- WAV는 16비트 PCM으로 제한되며 다른 클립과 합산한 결과가 0dBFS를 넘으면 클리핑될 수 있습니다.

## 검증
- 새 단위 테스트는 입력 검증, JSON 호환성, 모노 채널 보정, 클립 재생 설정과의 독립성 등을 확인합니다.
- Web Audio와 IndexedDB 모의 객체를 이용해 실제 `AudioEngine.play()` 및 `mixdownWav()` 함수를 호출합니다. 왼쪽/가운데/오른쪽 WAV의 **각 채널 PCM RMS**를 비교합니다.
- 합성 샘플 WAV는 사인파로 좌·중·우를 차례대로 들려주기 위한 별도 오프라인 예제이며, 실제 AI 보컬 생성 결과가 아닙니다.
- Windows 10·11 x64 실기기 GUI/WebView2/스피커 테스트는 별도로 필요합니다.
- GitHub, 외부 서버 및 클라우드 AI API를 사용하지 않습니다.
