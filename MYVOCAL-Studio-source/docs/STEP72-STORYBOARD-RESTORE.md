# Step72 — Storyboard JSON 검증·미리보기·복원 (로컬 전용)

Step71의 **장면 계획 JSON** 내보내기 결과를 같은 프로젝트의 Video Studio에서 다시 읽어들입니다.

1. Video Studio → `스토리보드 JSON 복원 · Step72` → 장면 계획 JSON 선택.
2. 512 KiB 이하의 파일을 로컬에서 검사합니다. 아직 프로젝트에 변경 사항이 없습니다.
3. 장면 수, 마지막 종료 시점, 공백, 경고를 확인합니다.
4. `검사한 장면 계획 적용 (기존 장면 교체)`를 클릭할 때에만 **해당 프로젝트의 장면 목록 전체**를 교체합니다.
5. 적용을 원치 않으면 취소합니다. 프로젝트의 장면 목록이 미리보기 이후 달라졌으면 가져오기를 다시 해야 합니다.

## 확인 항목
- `myvocal-mv-storyboard`, version 1, `manual-storyboard-metadata-only` 포맷.
- **같은 프로젝트 ID** 및 일치하는 프로젝트 BPM, 총 장면 수/길이/공백 요약.
- 장면 중복 ID, 0/음수 길이, 시간 겹침, 밀리초 정밀도, 2시간 제한, 지원하지 않는 추가 필드.
- 존재하지 않는 캐릭터 ID 및 영상 생성/립싱크 완료 주장 필드.
- 미디어 파일 경로·바이트·원본 음원 데이터와 원격 URL 등 추가 필드의 반입 금지.

## 제한 및 주의
- 기존 장면이 필요한 경우 **적용 전에 기존 장면 계획 JSON으로 별도 백업**하십시오.
- 파일은 수동으로 선택하여 읽고, 프로젝트의 다른 트랙·보컬·미디어·캐릭터 및 브라우저 프로필은 변경하지 않습니다.
- 장면을 교체하므로 외부에 별도로 저장된 큐/컷 연결은 사용자가 점검해야 합니다.
- 신규 영상 렌더링·AI 생성·자동 립싱크·네트워크 기능은 없습니다.
- Windows 10/11 네이티브 GUI, 실제 미디어 재생 및 장기 사용자 데이터 운영은 미검증입니다.
