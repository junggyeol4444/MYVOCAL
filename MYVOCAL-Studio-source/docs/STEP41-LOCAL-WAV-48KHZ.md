# Step41 — WAV 출력 샘플레이트 선택 (로컬 전용)

오디오·MIDI 멀티트랙 편집기의 WAV 믹스 저장에서 **44.1 kHz(기본값)** 또는 **48 kHz**를 선택합니다. PCM 16비트/24비트 및 선택형 -1 dBFS 샘플 피크 보호와 조합할 수 있습니다.

- 출력은 두 샘플레이트 모두 스테레오 정수 PCM RIFF/WAVE이며, 파일 이름은 기존과 같이 `프로젝트명-mix.wav`입니다.
- 변경 사항은 해당 세션의 WAV 출력 옵션에만 적용됩니다. 원본 WAV·MIDI·프로젝트 JSON·브라우저 프로필을 변경하지 않습니다.
- 기존 `mixdownWav(project)`는 44.1 kHz, 16비트 Blob 반환을 그대로 유지합니다. 예: `mixdownWavDetailed(project,{sampleRate:48000,bitDepth:24,peakProtection:true})`.
- 원본 클립과 출력 샘플레이트가 다르면 브라우저의 **OfflineAudioContext**가 재생 중 리샘플링합니다. 48kHz로 저장한다고 원본 녹음의 정보량이나 음질이 높아지는 것은 아닙니다. 브라우저 구현별 보간 방식은 다를 수 있습니다.
- 출력 길이는 선택한 샘플레이트의 샘플 수로 계산하며 최대 8분 제한을 유지합니다. 48kHz는 44.1kHz보다 같은 길이에서 PCM 데이터가 약 8.84% 큽니다.
- 지원하지 않는 샘플레이트는 오류로 거부합니다. 오디오 재생 엔진의 샘플레이트는 바꾸지 않습니다.
- 자동 테스트는 오프라인 오디오 모의 엔진과 RIFF/WAV 헤더 검사입니다. Windows 10/11 실기기에서의 WebView2, 오디오 장치, 타사 편집기 호환성은 별도 검증이 필요합니다.
