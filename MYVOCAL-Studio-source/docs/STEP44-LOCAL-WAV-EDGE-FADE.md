# Step44 — 로컬 WAV 출력 경계 5ms 페이드

기준: Step43 누적 전체 소스. 이 작업은 원본 66개 기획 중 음악 믹싱·마스터링 기능의 일부를 보완하며 새로운 100단계 상세 기획을 정의하지 않습니다.

## 동작

- WAV 내보내기에 **경계 페이드 (5ms)** 체크박스 추가, 기본값 꺼짐.
- 옵션을 켜면 WAV로 저장되는 최종 범위의 양 끝에 선형 페이드 인/아웃을 적용합니다. Step43 앞뒤 무음 제거를 켠 경우 무음 제거가 먼저 이루어지며 그 후의 새로운 경계에 페이드가 적용됩니다.
- 프레임 기준 첫 샘플과 마지막 샘플을 0으로 만들고, 그 사이에서 샘플레이트 기준 5ms 동안 1배로 변화합니다. 짧은 출력은 두 페이드가 겹치지 않도록 반 길이로 제한합니다. 1프레임 출력은 0으로 저장합니다.
- 기존 16/24비트, 44.1/48kHz, 모노/스테레오, 피크 보호 기능과 결합할 수 있습니다. 페이드는 PCM 인코딩 직전에만 적용되며 원본 오디오, 프로젝트 JSON, 재생, 미디어 저장소, WebView2 프로필을 변경하지 않습니다.
- 피크 보호는 페이드 전 신호로 계산하므로 피크 감쇠가 보수적일 수 있습니다. 피크 보호는 기존대로 선택 사항입니다.

## 한계

- 이 기능은 클릭 발생 가능성을 낮출 뿐, 모든 클릭이나 노이즈를 제거하지는 않습니다. 선택 시 의도된 어택/릴리스도 줄어듭니다.
- 실제 Windows 10/11 및 WebView2 기기 실행과 청감 테스트는 수행하지 않았습니다.
- `npm run build`는 Vite 미설치 환경에서는 실패하며, `npm run build:standalone`이 별도의 오프라인 HTML을 생성합니다. 오프라인 단일 HTML은 React19/Vite 정식 번들 대신 호환 런타임을 사용하므로 실제 UI 동작의 완전한 동등성은 실기기 검증이 필요합니다.
- 재현용 로컬 합성 WAV는 `node scripts/demo-wav-edge-step44.mjs <디렉터리>`로 생성합니다.
