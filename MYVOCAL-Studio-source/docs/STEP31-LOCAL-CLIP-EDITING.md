# Step31 — 로컬 오디오 클립 비파괴 위치·길이 편집

오디오·MIDI 멀티트랙 편집기의 **오디오 클립 위치 · 비파괴 자르기**에서 다음 값을 편집할 수 있습니다.

- **시작 마디:** 소리를 곡에서 재생할 위치. 소수점 마디 지원(예: 1.625마디).
- **원본 앞부분 건너뛰기(초):** 원본 음원에서 재생을 시작할 위치. 원본 파일을 수정하지 않습니다.
- **재생 길이(초):** 건너뛴 시작점으로부터 재생할 시간. 원본 길이를 초과할 수 없습니다.
- **자르기 초기화:** 원본 오디오 전체 길이로 돌아갑니다. 시작 마디는 유지합니다.

이 설정은 오디오 파형, 프로젝트 길이, 이동 재생 및 **WAV 믹스 내보내기**에 적용됩니다. 음원 원본은 IndexedDB에 별도로 저장되며 자르기 과정에서 재작성되거나 삭제되지 않습니다.

## 하위 호환

이전 프로젝트의 오디오 클립은 `startBar`와 `durationSec`만 있어도 그대로 전체 재생됩니다. 새 설정은 선택적 필드 `sourceOffsetSec`, `playDurationSec`에 저장됩니다. 기존 음악·보컬·영상 및 브라우저 프로필을 자동 이전하지 않습니다.

## 제한

현재는 시간 구간 편집이며 페이드인·페이드아웃·타임 스트레칭·피치 시프팅은 제공하지 않습니다. 브라우저/WebView2가 지원하는 오디오 형식의 파일을 불러올 수 있습니다. Windows 10/11 실제 사용자 PC GUI 검증과 실제 WebView2 COM 동작 검증은 여전히 필요합니다.

GitHub, 외부 서버, 정기 실행 예약은 이 개발본에 필요하지 않습니다.
