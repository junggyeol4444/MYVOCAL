# Step47 — WAV 선택 구간 내보내기 (로컬)

기존 Step46 누적 소스에 WAV 구간 선택을 추가했습니다. 원본 `docs/MYVOCAL-66-ORIGINAL.md`를 수정하거나 임의의 100단계 계획을 작성하지 않았습니다.

음악 편집기의 **선택 구간만 저장**을 체크하고 **시작(초)**과 **끝(초)**을 입력합니다. 타임라인 재생 커서를 원하는 위치로 옮긴 후 **커서→시작**, **커서→끝** 버튼으로도 값을 채울 수 있습니다. 구간은 프로젝트의 0초부터 끝까지의 절대 시간이며 끝 위치는 포함하지 않습니다. 시작 < 끝, 길이 1샘플 이상이어야 합니다. 44.1kHz와 48kHz 출력에서는 각 경계를 가장 가까운 샘플로 반올림합니다.

전체 믹스가 먼저 로컬 오프라인 엔진에서 렌더링되며, 선택한 구간만 WAV로 인코딩합니다. **앞뒤 무음 제거**는 선택 구간 안에서만 수행하며, 선택 구간 전체가 무음이면 선택 길이를 유지합니다. **피크 보호/정규화**는 실제로 내보내는 샘플만 분석합니다. **경계 5ms 페이드**는 내보내는 범위의 처음과 끝에 적용합니다. 기존 PCM 비트 깊이, 채널 수, 샘플레이트, TPDF 디더 선택과 함께 사용할 수 있습니다.

체크를 끄면 기존 전체 WAV 내보내기가 유지됩니다. 구간 선택 값은 프로젝트 JSON에 저장하지 않으며, 프로젝트·미디어·오디오 클립·WebView2 프로필을 수정하지 않습니다. 출력 파일 이름은 `프로젝트명-range.wav`이고 전체 믹스는 기존 `프로젝트명-mix.wav`입니다.

주의: 현재 구현은 전체 프로젝트를 먼저 렌더링하므로 긴 프로젝트의 메모리 사용량과 렌더링 시간은 선택 길이에 비례하여 줄어들지 않습니다. 8분 상한도 그대로 적용됩니다. 아주 짧은 구간의 경계 페이드는 오디오를 크게 감쇠시킬 수 있습니다. Windows 10/11 실기기 및 WebView2 실제 재생 테스트는 별도로 필요합니다.
