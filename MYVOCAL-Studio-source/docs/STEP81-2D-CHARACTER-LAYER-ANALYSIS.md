# Step81 — 2D 캐릭터 레이어 분석 (레이어 구조 준비)

## 범위

원래 100단계 로드맵의 **81단계**만 처리합니다. `82단계 2D 캐릭터 애니메이션`, `83단계 3D`, `85단계 Lip Sync` 및 이후 단계는 구현하지 않습니다.

이 단계는 기존 Character Library/프로젝트 자산을 보존한 채 다음을 제공합니다.

1. `Character Studio`에 등록된 사용 권한 있는 2D 캐릭터 원본 PNG/JPEG/WebP 로드 (로컬 IndexedDB만 사용).
2. 실제 RGBA 픽셀의 **알파 전경 경계** 측정. 투명 영역이 없으면 전체 이미지 크기를 사용.
3. 전경 외곽을 기준으로 **몸, 머리카락, 얼굴, 양쪽 눈, 입**의 6개 추정 사각형 생성. **의미적 객체/얼굴 인식 모델이 아니므로 초기값은 정확하지 않을 수 있음**.
4. 원본 위에 영역 표시, X/Y/너비/높이(px), 사용 여부, 중심점(0~1) 수동 수정 및 유효성 검증.
5. 영역별 PNG 추출(클립 사각형 안에 있던 **원본 픽셀 그대로**, PNG 다운로드), 구조 JSON 내보내기.
6. 검토한 레이어 영역 데이터(`character.layerPlan`)를 기존 캐릭터 프로필에 보존.
7. 프로젝트 통합 백업·복원 시 `layerPlan.sourceAssetId`를 복원된 원본 자산 ID로 재매핑. 기존 Step80 `characterMv`, Step79 `personMv`, Step77/78 생성 결과 유지.

## 실제 사용 방법

1. **Character Studio** → `2D 캐릭터 / 일러스트` 캐릭터와 원본 PNG/JPEG/WebP 등록. 본인 창작, 본인, 사용 허가 자료만 가능. 허가 자료는 허가 출처 필수.
2. 해당 캐릭터 카드의 `2D 레이어 분석·수정` 선택. 등록된 원본 그림을 선택하면 **픽셀 불투명 영역**에서 자동으로 후보 사각형 6개를 배치합니다.
3. 이미지 위 상자와 X/Y/W/H 좌표를 보면서 수동으로 수정합니다. 입/눈 등이 실제 위치와 다르면 반드시 조정합니다. 움직임 중심점 X/Y도 수정 가능합니다.
4. 필요한 부위를 `영역 PNG 추출`로 각각 내보내고, `레이어 분석 JSON`으로 좌표·중심점·참조 자산 ID를 내보냅니다.
5. `6개 레이어 구조 검토·저장`으로 캐릭터 프로필에 영역 계획을 저장합니다. 원본 픽셀/Step80 PV 데이터는 변경하지 않습니다.
6. 프로젝트 백업 후 복원한 캐릭터에서도 레이어 원본 연결이 유지됩니다.

## 제약 — 결과를 과장하지 않음

- **AI 안면 랜드마크, 부위 인식/세그멘테이션, 자동 머리카락 분리, 숨겨진 배경 재구성은 미구현**. 알파 경계와 정해진 비율에 따른 초기 **사각 영역 추정** + 사용자 수동 교정입니다.
- **PNG 사각형 크롭은 독립 투명 스프라이트/레이어 분리와 다릅니다.** 평면 JPEG에는 배경이 포함되며, 눈/입을 얼굴에서 제거하거나 가려진 눈꺼풀을 합성하지 않습니다.
- 출력은 6개 PNG 파일을 **사용자가 개별 다운로드**하는 방식입니다. 앱은 좌표 계획을 자동 저장하지만 PNG 추출 결과 자체를 앱의 새 자산으로 자동 등록하지는 않습니다. 다음 단계에서 이 구분을 반드시 유지해야 합니다.
- 실제 눈 깜빡임/입 모양/헤어/몸 애니메이션은 **82단계 이후**. 움직임, 카메라, 얼굴 키프레임을 생성했다고 주장하지 않습니다.
- UI 픽셀 분석·PNG 다운로드는 Windows WebView2 기반으로 구현됐으나 실제 Windows PC 클릭 테스트는 미검증입니다.
- 파일은 이미지 한 변 최대 4096px, 최대 1200만 픽셀. 큰 이미지는 먼저 축소해야 합니다.
