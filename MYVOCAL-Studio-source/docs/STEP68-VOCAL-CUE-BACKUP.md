# Step68 — 캐릭터별 수동 보컬 큐 백업 및 복원

기존 Step67 보컬 큐, Step66 캐스팅 보드, Step65 컷 계획과 Step61~63 룩 및 외형 기준을 유지합니다.

## 사용법
1. Character Studio에서 캐릭터 및 컷 계획을 등록하고 Step67 보컬 큐를 추가합니다.
2. 해당 캐릭터 카드의 **보컬 큐 개별 백업**을 누르면 `myvocal-character-vocal-cues` v1 JSON이 저장됩니다.
3. 같은 캐릭터의 기존 큐가 없거나 시간·ID 충돌이 없는 경우 **보컬 큐 JSON 복원**으로 추가할 수 있습니다.
4. 여러 캐릭터의 전체 보컬 타임라인 JSON은 Step67의 **보컬 큐 JSON 저장**을 사용합니다. 이 통합 타임라인은 구간별로 분할된 비교 자료로서 복원 입력 형식이 아닙니다.

## 보안·데이터 제한
- 캐릭터 ID 동일성, JSON 스키마, 연결 컷 존재, 큐 시간의 컷 범위 포함, ID 중복, 시간 충돌, 96개 제한, 원본 JSON 512KB 제한 검사.
- 전체 데이터를 검사한 후 단일 상태 교체. 오류 발생 시 원본 프로젝트/캐릭터 상태를 변경하지 않습니다.
- 캐릭터 원본 이미지·오디오·동영상·목소리·모델 파일은 JSON에 넣지 않습니다. 수동 가사/발화 메모는 포함되므로 파일 공유에 주의하세요.
- 컷이 수정되거나 삭제되어 연결이 끊어진 **기존** 큐는 백업할 수 있지만, 복원하려면 목적지의 연결 컷과 시간이 다시 유효해야 합니다.
- 입력 파일을 다른 캐릭터로 가져오기, 학습 데이터로 전환, 자동 립싱크, AI 학습·보컬 생성, 외부 네트워크 전송은 제공하지 않습니다.
