# v1.2 변경 내역

- Windows EXE 서버에 엔진 실행·중지·현재 상태·로그를 조회하는 API 추가
- UI의 Singing Workbench에서 엔진 프로세스를 직접 관리하는 패널 추가
- 외부 설치된 명령줄 가창 엔진에 JSON 입력·PCM WAV 출력을 전달하는 Python 어댑터 제공
- 모델 ID, 자료 권한, 입력 크기, 외부 WAV 포맷 제한 및 테스트 보강
- 자동 시작 없이 사용자가 실행 버튼을 누를 때만 엔진 프로세스 실행
- AI 모델 및 학습 알고리즘은 내장되지 않음. 기존 v1.1의 프로젝트 및 데이터 저장 방식 유지

상세 내용 및 테스트 범위는 상위 `BUILD.md` 참조.
