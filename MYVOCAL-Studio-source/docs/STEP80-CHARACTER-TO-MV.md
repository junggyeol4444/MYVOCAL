# MYVOCAL Studio — Step80: Character-to-MV

## 변경 범위 (계획 순서 고정)

- **80단계만** 구현: 사용자가 Character Studio에 등록한 2D 캐릭터 그림을 기반으로 음악 프로젝트의 Storyboard 장면에서 짧은 애니메이션 PV 클립 생성.
- 기반: Step77 SD 로컬 정지 이미지, Step78 ComfyUI SVD 짧은 애니메이션 WebP, Step79 인물 사진과 별도 사용 경로. Step76 MV 연출/Storyboard 위치 정보 재사용.
- 81단계의 눈/입/몸 레이어 분석, 82단계의 2D 관절 애니메이션, 85단계 Lip Sync, 98단계 오디오 포함 MP4 합성은 **이번 단계가 아님**.

## 실제 사용

1. **Character Studio**에서 `2D 캐릭터 / 일러스트`로 캐릭터 생성, 원본 PNG 또는 JPEG 등록. 권한은 직접 창작(owned), 본인(self), 또는 사용 허가(licensed + 허가 범위 기재). Reference 전용, 실제 사람·3D 모델, 그리고 현재 WebP 원본은 이 단계의 원본 입력 대상이 아님.
2. **Windows EXE**에서 로컬 ComfyUI 서버(기본 127.0.0.1:8188)에 SD 이미지 모델과 호환 SVD/SVD-XT 모델을 설치하고 실행. ZIP/EXE에 모델을 포함하지 않음.
3. Video Studio Step77에서 로컬 이미지 엔진 검사 후 체크포인트 선택, Step78에서 영상 모델 검사 후 SVD 체크포인트 선택. 스토리보드 장면, 등장 캐릭터·배경·카메라 등의 설명과 시간을 설정.
4. **Step80 Character-to-MV** 패널에서 캐릭터와 실제 등록한 그림 선택. 변환 강도(0.20 기본 선택 가능)·시드 선택. `선택 장면 캐릭터→PV 클립 생성` 또는 `전체 해당 장면 순차 제작` 실행. 기존 다른 캐릭터로 지정한 장면은 전체 처리 대상에서 제외.
5. 원본 PNG/JPEG를 로컬 ComfyUI의 `LoadImage → ImageScale → VAEEncode → KSampler(img2img)`로 전달해 **장면별 정지 이미지**를 저장. 이어 해당 실제 생성 이미지를 SVD `img2vid` 입력으로 사용하여 **장면별 14/25프레임 WebP** 생성·저장. 저장소는 기존 IndexedDB이고 프로젝트의 `characterMv`로 원본 그림 ID를 연결함.
6. 스토리보드 애니매틱에 캐릭터 PV 클립이 있다면 해당 장면 위치에서 반복 표시. 장면 이미지/영상 개별 내보내기 및 프로젝트 미디어 백업·복원은 기존 기능 재사용.

## 실패·보존

- 모델, 세션, 권한, 이미지 형식, 원본 파일 또는 ComfyUI 노드 문제 발생 시 명확한 오류. 모델이 없는데 생성한 것으로 표시하지 않음.
- 생성 도중 프로젝트·장면·캐릭터·그림이 변경되면 새 결과를 장면에 연결하지 않음.
- 단계별 진행: 이미지 저장 후 영상 생성 실패 시 저장된 이미지는 보존. 이전 원본·기존 음악 트랙·장면 클립은 명시적인 별도 삭제 없이 유지.
- 실제 사람 선택은 Step79에서, 2D 그림 선택은 Step80에서만 수행. 하나의 장면이 두 경로를 동시에 참조하지 않도록 연결 메타데이터를 전환함.

## 실제 제약

- **AI GPU 추론 및 Windows 10/11 UI 실기기 테스트는 이 빌드 환경에서 미검증.** Go 모의 HTTP ComfyUI 서버에서 원본 이미지 바이트 전송·그래프 제출·결과 수신을 검증함.
- 일반 SD img2img + SVD 영상은 캐릭터 얼굴, 의상, 화풍의 컷 간 동일성을 보장하지 않음. 애니메이션 WebP는 짧은 반복 영상이며 장면 길이 전체를 렌더링하거나 노래/보컬 오디오에 시간 정합되지는 않음.
- 완성된 긴 PV/뮤직비디오 MP4나 입 모양/가창/춤 동기화를 이번 단계에서 구현했다고 주장하지 않음.
- 외부 서버로 전송하지 않도록 로컬 ComfyUI 연동만 이용하며 등록 권리는 **사용자 선언**에 근거함. 서버는 계약서 진위를 판별하지 않음.
- 캐릭터 등록 PNG/JPEG 12MB 제한, 장면 저장 이미지 12MB 제한, 애니메이션 클립 40MB 제한. 기존 프로젝트 통합 백업에는 미디어 총 150MB 제한.
