# MYVOCAL Studio v0.5

## 실제 구현
- Voice Studio: 마이크 녹음(최대 2분), 로컬 오디오 파일 업로드, 기존 프로필에 다중 샘플 추가/재분석/삭제
- AudioContext 디코더로 단일/다채널 오디오 분석: RMS/피크/클리핑 비율, 일정 시간 간격의 단일 음 피치 추정, 대략적인 대표 음정과 10~90백분위 음역, 시간별 그래프
- 오디오 분석 중 진행률 제공, 실패한 샘플도 원본 저장
- 기존 v0.4 기능, 로컬 데이터 스키마/저장 키, 편집기 유지

## 한계
- 이 신호 분석은 음성/음소/개인 식별/창법/비브라토 학습을 수행하지 않음. 반주가 있는 파일에서 음높이가 부정확할 수 있음.
- 원본 파일은 앱 브라우저 프로필의 IndexedDB에 저장됨. 설정의 JSON 백업만으로 원본 복원이 불가하므로 별도 원본 파일을 보관해야 함. 연결된 프로젝트 번들에는 연결된 보이스 샘플 자산이 포함됨.
- AI 목소리 학습, Singing 합성, AI 보컬 변환은 미구현.
- Windows 실기기 검증은 아직 수행하지 않았음.
