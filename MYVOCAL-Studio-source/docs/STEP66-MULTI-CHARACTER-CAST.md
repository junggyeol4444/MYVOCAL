# MYVOCAL Step66 — 캐릭터 동시 출연 타임라인

## 이전 단계와 연결
Step65에서 저장한 캐릭터별 `shots` 및 룩 프리셋을 **읽기 전용**으로 모아 하나의 MV 시간축을 계산한다. 기존 캐릭터/룩/샷 스키마, IndexedDB, 프로젝트, 웹뷰 프로필을 삭제하거나 재작성하지 않는다.

## 사용 방법
1. Character Studio에서 최소 2명의 캐릭터를 등록하고 각자 룩 및 컷 시간 계획을 만든다.
2. 페이지 상단 **MULTI-CHARACTER CAST · STEP66**에서 출연자를 체크박스로 선택한다.
3. 같은 시간에 2명 이상 출연하면 **동시 출연**으로 표시한다. 같은 캐릭터의 시간 중복은 기존 컷 입력에서 금지한다.
4. 빈 구간과 **룩 재검토 필요** 경고를 확인한다.
5. **캐스팅 JSON 저장**으로 출력한다. JSON은 메타데이터만 포함하고 이미지, 영상, 음원, 3D 모델 바이트는 포함하지 않는다.

## 로컬 API
- `buildCharacterCastTimeline(characters)` — 입력을 수정하지 않고 시간 구간별 출연자를 계산. 마이크로초 또는 부동소수점 시간 오차를 피하려고 시간을 정수 밀리초로 변환한다.
- `exportCharacterCastTimeline(characters)` — `myvocal-character-cast-timeline` v1 JSON 데이터 생성.
- 동일 캐릭터의 잘못된 레거시 시간 겹침, 중복 ID/컷 ID, 잘못된 시간, 64명 이상, 캐릭터당 48컷 초과는 거부한다.
- 서로 **다른** 캐릭터의 컷 시간 겹침은 오류가 아니라 동시 출연으로 처리한다.

## 의도적으로 구현하지 않은 항목
실제 보컬과 캐릭터의 연결, 화자 분리, 음성/입술 동기화, AI 캐스팅, AI 얼굴 인식, 자동 Identity Lock, 2D/3D 애니메이션, 영상 렌더링 및 Windows 실기기 동작 테스트는 이 단계 범위 밖이다. "듀엣"은 시간상 동시 출연의 편집 메모이며 실제 두 가수의 음원이나 퍼포먼스 결과가 아니다.

## 수동 예제
`examples/step66/`의 합성 캐릭터 두 명이 0~6초, 3~9초 등장한다. 3~6초는 동시 출연이다. 실제 사용자 자료가 아니다.
