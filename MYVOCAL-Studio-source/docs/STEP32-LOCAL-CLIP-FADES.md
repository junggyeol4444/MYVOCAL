# Step32 · 로컬 오디오 클립 페이드 편집

오디오 트랙의 각 클립에 `fadeInSec`, `fadeOutSec`(초)를 선택적으로 저장합니다.

- 기존 프로젝트에서 두 속성이 없으면 **페이드 없음**으로 재생되므로 마이그레이션이 필요 없습니다.
- 페이드 길이는 클립 재생 범위 안쪽만 허용합니다. 자르기로 인하여 합계가 재생 길이보다 길어지면 재생 때만 비례 축소하여 기존 저장값을 안전하게 보존합니다.
- 실시간 Web Audio 재생, 중간 위치부터 재생(Seek), 44.1kHz 스테레오 WAV 믹스 모두 동일한 **선형 게인 페이드**를 사용합니다.
- 페이드 게인은 트랙별 볼륨·음소거·솔로와 분리되어 있으므로 트랙 믹서 조작도 정상적으로 유지됩니다.
- 자르기 초기화 버튼은 트림만 초기화하고 페이드 메타데이터는 유지합니다.
- 원본 오디오 파일과 IndexedDB 저장소는 수정하지 않습니다. 로컬 작업이며 인터넷·GitHub 호출이 없습니다.
- Windows 10/11 실기기에서 GUI와 실제 재생을 확인한 것은 아니며 자동 테스트·크로스 빌드만 검증합니다.
