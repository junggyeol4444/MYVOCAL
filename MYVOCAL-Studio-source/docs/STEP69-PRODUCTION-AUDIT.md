# Step69 — 캐릭터 MV 제작 계획 메타데이터 점검

누적 출발점: Step68. `Character Studio`의 다중 캐릭터 캐스팅 보드 아래 **PRODUCTION AUDIT · STEP69**에서 확인합니다.

## 사용

1. 기존 캐릭터의 외형 기준, 룩, 컷, 수동 보컬 큐를 작성합니다.
2. 다중 캐릭터 출연 보드에서 표시할 캐릭터를 선택합니다.
3. 제작 점검 패널의 오류·경고·참고 항목을 확인합니다. 오류나 경고 항목에 연결된 컷/큐를 수동 수정합니다.
4. **제작 점검 JSON 저장**으로 현재 선택 캐릭터의 점검 결과만 로컬 파일로 내보냅니다.

## 검사 범위

- 캐릭터 ID 중복, 컷/큐 ID 중복, 각 캐릭터 내부 컷·큐 시간 겹침과 밀리초 경계 검증
- 컷의 룩 연결 누락, Step62 기준 외형 변경, 룩의 참고 자료 누락
- 큐의 컷 연결 누락, 컷 범위 밖 시간, 지원하지 않는 역할
- 리드 및 대사 큐의 빈 가사 메모는 경고 (가사 내용 검사 없음)
- 큐가 없는 컷은 **참고**만 표시. 연주/영상만 있는 컷은 정상적으로 사용할 수 있음
- 다른 캐릭터의 같은 시간 큐는 정상적인 동시 출연/듀엣 계획으로 집계

**메타데이터 연결 점검 통과**는 기획 데이터에서 오류·경고가 발견되지 않았다는 의미에 한정됩니다. 영상이나 음악을 만들었다는 의미가 아닙니다.

## 개인정보 및 범위

보고서에는 캐릭터/컷 제목과 ID, 시작·종료 시간, 문제 코드 및 메시지만 포함합니다. 원본 음원·영상·이미지·모델 바이트와 가사 원문, 연출 메모는 포함하지 않습니다. 파일/프로젝트/IndexedDB/WebView2 프로필은 수정하거나 초기화하지 않습니다. 네트워크, 외부 AI, 립싱크 또는 렌더링은 사용하지 않습니다.

캐릭터 이름과 컷 제목 및 촬영 시간은 JSON에 포함되므로 외부 공유 시 검토하세요.
