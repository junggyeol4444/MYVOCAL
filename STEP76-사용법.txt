MYVOCAL Studio Step76 — 기존 Step75 위에 누적된 Windows 프로그램

1. MYVOCAL-Step76-Windows.exe 파일을 기존 실행 파일과 구분되는 위치에 둡니다.
2. Windows 10/11에서 실행합니다 (실기기 검증 미실시).
3. 기존 프로젝트를 열고 Music Video Studio로 이동합니다.
4. Step76 · MV 연출 모드에서 Performance / Story / Mixed MV 및 캐릭터 등장 강도를 선택합니다.
5. 장면별 연출 계획을 보고, 필요하면 선택 장면 역할을 변경합니다.
6. 연출 큐시트 JSON 저장을 누르면 현재 프로젝트의 연출 메타데이터만 저장됩니다.

주의: 실제 AI 영상 생성 기능이나 영상 파일 저장 기능은 이번 단계 범위가 아닙니다.
컴퓨터에 호환 Edge/Chrome 또는 WebView2 런타임이 필요할 수 있습니다.
기존 사용자 데이터와 프로그램 프로필은 지우거나 초기화하지 마십시오.
